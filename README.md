# <h1 align ="center"> 2 &deg; Projeto de Certificação DEVStart </h1>
<p align="center" >
Aplicação que recebe o nome e notas de um atleta, calcula a média, IMC do atleta e exibe o resultado ao usuário
</p>

---

## 🚀 Tecnologias utilizadas
* Node.js
## ▶️ Como executar 
- 1- Clone o repositorio
```bash
git clone https://github.com/dev-grodrigues-dados-atletas
```
- 2- Abra o arquivo 
```bash
node dados-atletas.js
```
